用户手册

PuMail

Less is more

一快速开始

添加入口
进入「设置 → 账号」页面，点击“添加邮箱账号”。
数量上限
最多支持绑定 6 个邮箱账号。
邮箱授权
QQ / Google 等需开通 IMAP 授权码，见操作指南。
退出账号
可选择是否保留本地邮件数据。

二账号管理

列表展示
显示邮箱图标、自定义名称及邮箱地址。
排序与显示
通过拖拽调整账号顺序；主界面左下角优先显示排序靠前的前 3 个邮箱。
密码管理
首次绑定时需设置 6 位主密码，用于本地加密保存各邮箱的授权码、应用密码及翻译 API 密钥。数据仅存储于本机，不会外泄。 若忘记主密码，需删除本地加密文件后方可重新使用该功能。

三主界面

左栏 · 导航与账号

  • 顶部：写邮件按钮、基础文件夹（收件箱、已发送、星标、草稿、垃圾邮件、已删除）。
  • 中部：Gaia·总览按钮，用于总览当前登录的所有邮箱的收件箱、已发送和草稿，方便快速收取新邮件。
  • 下部：已绑定邮箱列表（仅显示排序前 3 个），底部为“设置”入口。

中栏 · 邮件列表

  • 顶部：支持刷新当前邮箱，以获取最新邮件；支持搜索邮件。
  • 列表：支持右键邮件进行星标、置顶和删除操作；支持同时选中多个邮件。

右栏 · 正文区

  • 支持对邮件进行星标、置顶和删除。
  • 回复：默认选择当前发件人，可手动更改收件人。
  • 灯泡：配置翻译 API 后，支持一键切换原文 / 翻译。

四其他设置

外观
支持深色主题（极简黑 + 青绿）与浅色主题（极简白 + 灰蓝）。
翻译
支持接入 DeepSeek / OpenAI / 自定义大模型 API。配置完成后，主界面右上角灯泡按钮启用，可一键切换原文 / 翻译；目标语言默认为简体中文。
存储
展示应用安装位置与数据存储位置，支持更改路径与打开路径，邮件本地数据依此路径保存。
关于
显示版本信息，提供用户手册入口，可查看隐私协议并进行意见反馈。
