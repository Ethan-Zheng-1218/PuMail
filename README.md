# PuMail

A local desktop email client. Supports QQ Mail, 163, Gmail, Outlook and iCloud.
Everything runs on your own machine: a small Python backend talks to your mail
providers directly over IMAP / SMTP, and an Electron shell wraps it into a
Windows desktop app.

### Features

- Multiple accounts at once — QQ Mail, 163, Gmail, Outlook, iCloud, or any
  custom IMAP/SMTP server
- Real IMAP IDLE push, with automatic back-off and fallback to polling when a
  provider rejects it
- Unified inbox, unread counts and new-mail notification (tray icon blink plus
  a sound)
- Read, reply, compose, attachments, drafts and inline translation
- Two ways to run: as a local web preview, or as a packaged Windows app

### Privacy

PuMail is a local client. Account passwords are kept in `~/.PuMail` on your own
machine and are only used to connect to your mail provider. There is no PuMail
server in the middle.

### Requirements

- Python 3.10+ (developed and tested on 3.12)
- Node.js 18+ — only for the Electron shell and packaging

### Run from source (web preview)

```bash
git clone https://github.com/Ethan-Zheng-1218/PuMail.git
cd PuMail
python -m pip install -r requirements.txt
python server.py
```

Then open <http://127.0.0.1:5000>.

On Windows you can also just double-click `打开PuMail网页版.bat`, which finds a
suitable Python, checks that port 5000 is free and starts the server for you.

### Desktop shell (development)

```bash
cd electron
npm install
npm start
```

In development the shell launches the PyInstaller backend from `dist/PuMail`, so
run the packaging step below at least once before `npm start`.

### Build a Windows installer

```bat
pack.bat
```

This runs two steps: PyInstaller builds the backend into `dist/PuMail`, then
electron-builder produces the installer at `PuMail-build\PuMail-Setup.exe`.
Packaging needs three extra packages:

```bash
python -m pip install pillow pyinstaller
```

### Tests

The test suite does not touch the network or a real mailbox — it uses fake IMAP
connections, a temporary database and a fake IMAP server.

```bash
python test_sync_queue.py
python test_idle_handshake.py
python -m unittest test_receive_pipeline test_unread_counts
node test_port_probe.js
```
