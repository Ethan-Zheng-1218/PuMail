# PuMail

A local desktop email client for QQ Mail, 163, Gmail, Outlook, iCloud and custom IMAP/SMTP providers.

[中文](../README.md) · [Download](https://github.com/Ethan-Zheng-1218/PuMail/releases) · [Account setup guide](../frontend/guides/邮箱绑定指南.md)

## Features

- Multiple accounts and a unified inbox
- IMAP IDLE push with polling fallback
- Read, compose, reply, attachments, drafts and inline translation
- Unread counts, tray notifications and new-mail sounds
- Windows desktop app and local web preview

## Quick start

Check [Releases](https://github.com/Ethan-Zheng-1218/PuMail/releases) for Windows installers.
To run from source, install Python 3.10 or newer:

```bash
git clone https://github.com/Ethan-Zheng-1218/PuMail.git
cd PuMail
python -m pip install -r requirements.txt
python -m backend.server
```

Open <http://127.0.0.1:5000>. On Windows, after installing dependencies,
you can also double-click `scripts/打开PuMail网页版.bat`.

## Development

See [development](development.md) for virtual environments and the directory layout,
[testing](testing.md) for checks, and [Windows packaging](building.md) for build details.
These detailed guides are currently in Chinese.

Runtime dependencies are in `requirements.txt`. Windows build dependencies are in
`packaging/requirements.txt`. From an activated Python environment at the repository root:

```bash
python -m pip install -r packaging/requirements.txt
scripts\pack.bat
```

The build script generates installer artwork, packages the Python backend,
and runs `npm ci` and `npm run pack` in `electron/` (Node.js 18+ required).
The installer is written to `PuMail-build/PuMail-Setup.exe`.
After building the backend, run `npm start` in `electron/` for the development shell.

## Privacy

PuMail's mail backend runs on your machine and connects directly to providers over IMAP/SMTP.
Account credentials and mail data are stored in `.PuMail/` under your user directory by default.
See the in-app [privacy page](../frontend/privacy.html) for details.
