# 更新日志

## 1.1.12 — 2026-11-25 重打包

- 安装 EXE 自行准备可写临时目录，再启动安装向导；无需外部 CMD，不修改 Windows 的 TEMP/TMP 设置。
- 点击“回复”后直接聚焦正文，保留自动填写的收件人。
- 全部账号收件箱未读数归零后，停止任务栏和托盘闪烁；直接打开邮件也会刷新提醒状态。
- 提醒以全部账号的完整未读汇总为准，并防止过期查询误清除新邮件提醒。

## 1.1.11

- 邮件正文中的纯文本 HTTP/HTTPS 网址自动变为可点击链接，用系统默认浏览器打开。
- 跳过已有链接和脚本，排除网址末尾的中文标点；翻译恢复后仍可点击。

## 1.1.10

- 附件在应用内带会话下载并保存，修复浏览器缺少本地登录状态导致的下载失败。
- 显示下载中和失败状态，保留真实附件文件名，防止重复下载。

## 1.1.9

- 多选时点击邮件行，同时勾选并打开正文；重复点击保留选中状态，复选框仍可取消选择。

## 1.1.8

- 移除阅读区上一封/下一封按钮和 J/K 快捷键；保留翻译、星标、置顶、回复和删除。

## 1.1.7

- 补齐构建运行库需要的 TLS 证书策略资源，修复安装版邮箱连接前的文件缺失错误。
- 本地 TLS 资源缺失不再误报为网络故障；代理状态区分检测到配置和实际连接结果。

## 1.1.6

- 回复和写信显示发送进度，防止重复提交；失败保留输入，结果不确定时提示核实。
